## 三、标注口径（MiMo 详细版）

> ⚠️ 此口径由卷014/015 远端定稿确立，**全批次必须一致遵循**。

### 名词标注（18类）

| 类型 | 标记 | 示例 | 说明 |
|---|---|---|---|
| 人名 | `〖@X〗` | `〖@匡衡〗` | 裸标为主；单字名强制消歧 |
| 谥号单用 | `〖@X〗` | `〖@节侯〗` | 指向本人侯号 |
| 亲属/属 | `〖#X子〗` | `〖#帝舅子〗` | 整体标身份 |
| 时间 | `〖%年月日〗` | `〖%建昭三年七月癸亥〗` | 整体一标 |
| 时长 | `〖%X｜时长〗` | `〖%二十一年｜时长〗` | 用全角｜ |
| 官职 | `〖;X〗` | `〖;丞相〗` | 含外邦职官（单于等） |
| 爵位泛称 | 不标 | "侯" | 功状列中"侯"不标 |
| 国名 | `〖◆X〗` | `〖◆匈奴〗` | 邦国 |
| 地名 | `〖=X〗` | `〖=汝南〗` | 末尾郡名 |
| 户数 | `〖$X〗` | `〖$六百四十七户〗` | |
| 酎金 | `〖:酎金〗` | | 礼仪类 |
| 刑罚 | `〖[城旦〗` | | 刑法类 |
| 族群 | `〖~X〗` | `〖~氐〗` | 非邦国族群 |
| 王号 | `〖;X王〗` | `〖;东平王〗` | "为X王"格式 |

### 动词标注（4类）

| 类型 | 标记 | 触发词 | 示例 |
|---|---|---|---|
| 正向动作 | `⟦○X⟧` | 立/封/嗣/薨/废/徙/绍封/免/复 | `⟦○封⟧` |
| 反叛 | `⟦◈X⟧` | 反/谋反 | `⟦◈反⟧` |
| 诛杀 | `⟦◉X⟧` | 诛/自杀/要斩/弃市/下狱死 | `⟦◉自杀⟧` |
| 不标 | — | 祝诅/杀人/贼杀/禽兽行/降/瘐死 | 罪名描述不标 |

### 特殊规则

- **"王莽篡位"不标动词**（裸字保留）
- **"薨"标 `⟦○薨⟧`**，**"免"标 `⟦○免⟧`**
- **"为X公"标 `为〖;X公〗`**（官职类）
- **功状列**："将军"/"太守"/"都尉"/"校尉"标 `〖;〗`；"降"不标动词

## 四、工具使用方法

### 1. 单段标注

```bash
python3 /workspace/hanshu-KB/scripts/annotate_station_local.py
# 交互式，BASE=/workspace/hanshu-KB
```

### 2. 批量标注（推荐）

**步骤 1**：写 JSON 到 `scripts/ws_cache/bXXX_pN.json`

```json
{
  "[r86]": "[r86] 〖@乐安侯匡衡〗｜以〖;丞相〗侯，〖$六百四十七户〗。｜〖%建昭三年七月癸亥〗⟦○封⟧，〖%七年｜时长〗，〖%建始四年〗，坐颛地盗土，⟦○免⟧。｜｜｜｜〖=僮〗"
}
```

> ⚠️ JSON 值**必须包含段号前缀**（如 `[r86]`），否则校验失败！

**步骤 2**：执行批量标注

```bash
python3 /workspace/hanshu-KB/scripts/ann_batch.py 卷018_外戚恩泽侯表第六 /workspace/hanshu-KB/scripts/ws_cache/b018_p5.json
```

> 注意：ann_batch.py 参数1用**底本文件名**（不含路径），参数2用 JSON **绝对路径**。

### 3. 校验

```bash
python3 /workspace/hanshu-KB/scripts/verify_annotation.py \
  /workspace/hanshu-KB/data/chapter_numbered/卷018_外戚恩泽侯表第六.txt \
  /workspace/hanshu-KB/kg/entities/标注/卷018_标注.txt
```

输出 `PASS 名词N 动词N 长度N` 即通过。

### 4. 提交推送

```bash

timeout 30 git -C /workspace/hanshu-KB push origin main 2>&1
```

## 五、常见错误与注意事项

### 易错点

1. **形近字误写**：吴→呉、温→浩、审→宛——标注前先 grep 底本确认原文
2. **空格保留**：原文中的空格必须保留（如"南阳 元鼎元年"）
3. **段号前缀**：JSON 值必须含 `[rN]` 前缀，否则 ann_batch 校验失败
4. **cd 禁用**：bash 中 `cd /workspace/hanshu-KB` 会触发 `S0.globalConfigFile` 错误，用 `git -C` 代替
5. **不标行**：列名行（`号谥姓名｜侯状户数｜...`）和小结行（`右高祖` 等）不标
6. **全角｜**：时长标记用全角竖线 `｜`（U+FF5C），不是半角 `|`

### 校验失败排查

- `FAIL 内容不一致` → 有原文被改动，逐段对比底本
- `FAIL 长度不等` → 漏标或多了字符，检查 JSON 值
- `FAIL 段号缺失` → JSON key 与底本段号不匹配
