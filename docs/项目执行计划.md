## 1. 总体判断：迁移可行性

依据 `00-META-13` 的相似度评估：**《史记》→《汉书》相似度约 85%**（同为纪传体、时代接近、重叠章节多），属于"Level 1 直接复用为主 + Level 2 适配调整"场景，预期 2-3 轮试点迭代收敛。

三条已写进 SKILL 体系的直接利好：

1. **迁移方法论现成**：`00-META-13` 本身就是以"史记→汉书"为第一案例写的，含迁移检查清单、错误日志模板（`doc/transfer/史记→汉书_迁移日志.md`）、成本公式。
2. **汉书数据已被史记项目引用过**：官职分类 SKILL_03i 的 L2.5 层白名单（`KNOWN_HAN_OFFICIALS`，约 300 条）就是用 `extract_hanshu_baiguan.py` 从 `corpus/other/汉书.txt` 卷十九上《百官公卿表》提取的——汉书项目可以直接白嫖这个冷启动词表。
3. **多处 SKILL 显式声明适用汉书**：`SKILL_04a`（"适用于纪传体史书如《汉书》"）、`SKILL_01b`（"可扩展至《汉书》"）、`SKILL_01e`（架构动机就是扩展到数千部古籍）、`SKILL_02a`（已给出汉书规模预估：120 篇 / 约 10,000 段落 / 约 1,100 小节）。

**主要成本中心**（00-META-13 与子代理精读一致结论）：消歧层（人名/年份）、八表结构分析、各工序提示词按"纪/表/志/传"重写。

### 2.3 预处理流水线（完全复用史记管线形状）

```
汉书单文件 → data/chapter/（按 120 卷切分，纯文本，lint 基准）
          → chapter_improved/（保留空行）
          → chapter_numbered/（PN 段落编号）
          → chapter_md/*.tagged.md（实体标注工作区）
```

- **繁简**：采用 `SKILL_01e` 已验证架构——**单一简体底本 + OpenCC + 词组规则**，仅在展示层做繁体切换。理由（原文四条）：中间分析无法维护双份、可扩展、人工校勘不可复现、LLM 基于简体训练识别率更高。词表规则须按汉书重做统计（禁单字规则、只用 2 字以上词组规则）。
- **校勘**：沿用 `SKILL_01b` 六原则 + 外证/内证方法论 + 派生文件同步 SOP（sed 精确替换、不用 cp 覆盖、〖〗数量校验）。史记的校对工时参考（270 小时）需按汉书 120 卷×体裁重估。
- **PUA 缺字 185 处**：列入首批校勘 Issue，优先用维基文库参校本回填。

### 2.4 时间体系资产复用（实测结论）

- `kg/chronology/data/reign_periods.json`（390 君主）中**汉代君主 11 位（高皇帝→平帝一线）、汉代年号 32 组全部已建**（含建元/元光…孝文后/孝景中/孝景后等映射）——武帝太初以前的时间骨架可直接复用。
- **缺口**：王莽不在 rulers 中；昭帝至平帝各年号（始元/元凤/本始/地节/初元/建始/元始/居摄/始建国/天凤/地皇等）需按《汉书》纪/表扩充映射。汉代年号纪年正是 `SKILL_03g` 五层消歧里 era_name 层的输入，此项在汉书管线中**从可选扩展升级为必做核心**（史记项目自己汉朝年表 017-022 都没做完，38.4% 覆盖缺口恰是汉书主体）。
- `SKILL_04b` 的**秦历十月岁首陷阱须拆成两段**：前 221—前 104（太初改历）十月为岁首；太初元年（前 104）后改太初历、以正月为岁首。汉书跨两段历法，逐条事件年代标注必须区分。

### 3.2 切分规则（复用 `SKILL_02a`，调整点见备注）

- **PN 编号体系原样复用**：`[1]`/`[1.1]`/`[1.1.1]` 三级、方括号纯数字、父子铁律（有 `[67.1]` 必有 `[67]`）、编号不可变、`[0]` 篇名段、表类行编号 `[rN]`、HTML 锚点 `#pn-{number}`。质检用 `lint_purple_numbers.py` / `fix_missing_parent_pn.py` 等现成脚本。
- **必须参数化的史记硬编码**（02a 已自列）：
  - `CHAPTER_PATTERNS = ['本纪','表','书','世家','列传']` → 改为 `['纪','表','志','传']`（无世家，"书"改"志"）；
  - "太史公曰"块标记 → 汉书各篇末为 **"赞曰"**（02a 明确提示其他史书是"论/赞/评"）；

  - 规模常量按 120 篇 / 约 10,000 段落 / 约 1,100 小节重估。
- **无明确分段的章节**：史记约 41 篇用启发式自动生成小节标题（准确率约 60%，必须人工审核）——汉书志类（律历/五行/天文）结构更规整，预期能好一些；仍按"自动+人工审核"执行。

## 5. 汉书特有实体的调整点

（实体**类型符号体系 18 类名词 + 4 类动词不变**，调整的是词表、分类成员与权重。）

### 5.1 官职（〖;〗）——最大调整面
- 汉代三公九卿体系（META-13 示例清单：大司马/大司徒/大司空；太常/光禄勋/卫尉/太仆/廷尉/大鸿胪/宗正/大司农/少府；太尉/御史大夫/丞相）。META-13 预估官职词表需扩展（史记 230 个 + 汉代新增约 120 个）。
- 《百官公卿表》既是校勘对象又是词表来源：`extract_hanshu_baiguan.py` 现成脚本 → `hanshu_baiguan.json`（约 300 条，分 sangong/jiuqing/liqing/palace/military/junli/other）直接作为冷启动白名单。
- 汉书时代新增须补：尚书台诸官、州牧/刺史、西域都护/戊己校尉、使匈奴中郎将、诸将军号系统。

### 5.2 爵位（〖;〗职类"爵位"）
- 二十等爵制贯穿全书；诸侯王/列侯/关内侯封除是八表主体，`封…为X侯`、`赐爵X` 共现规则（SKILL_03i L3）直接命中。

### 5.3 身份与外戚（〖#〗）
- 太后/外戚/大司马录尚书事是西汉政治主线；《外戚传》《外戚恩泽侯表》为专门语料。史记 03i 的"身份误标"类经验（太后/太子/夫人应标 〖#〗）迁移时权重上调。

### 5.4 邦国与族群（〖◆〗〖~〗）
- 西汉一朝：邦国标注密度下降（META-13），主体为 〖◆汉〗+诸侯王国+匈奴；**匈奴职官**（单于/左右贤王/谷蠡王/当户/且渠/骨都侯）与**西域诸国**（《西域传》都护体系）是新增语料——史记 03i"外邦职"类规则可迁移，但西域都护这种"汉官管西域"的双归属需在分类规则中明确。

### 5.5 年号纪年（〖%〗）
- 汉代核心特征（建元/元狩式纪年密集）。处理：优先 era_name 年号映射层（§2.4）；`00-META-13` 阶段 3 反思模板已预留"新增〖*年号〗独立类型 vs 复用〖%时间〗"的决策点——**建议试点后决策**，倾向复用〖%〗+后处理解析（少一类标注负担，映射靠 reign_periods 扩充）。

### 5.6 事件类型权重（04a 11 类）
- META-13 预测：战争 23%→15%↓、政治改革→25%↑、继位→10%↓。增补汉书高频事件面：灾异（五行志）、盐铁/均输平准、经学与博士制度、外戚擅权、王莽改制（托古改制事件群）。

### 5.7 下降的实体面
- 〖?神话〗：五帝传说仅在《古今人表》《叙传》少量出现，权重下调。
- 〖&氏族〗：先秦氏族叙事减少，但王氏/史氏/许氏等西汉外戚宗族语料上升。
