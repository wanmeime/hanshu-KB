# 汉书知识图谱 (Knowledge Graph)

从《汉书》120 卷（100 篇）中提取的结构化知识。目录骨架依 TASK-003 建立，
参考 shiji-kb-reference/kg/ 的组织方式，数据随后续里程碑逐步填充。

## 目录结构

```
kg/
├── entities/      # 实体（人物、官职、地名、氏族、典籍等）
├── events/        # 事件（依 SKILL_04a 框架，事件 ID {三位卷号}-{三位序号}）
├── facts/         # 事实（人物-属性、制度-条文等原子事实）
├── relations/     # 关系（人物关系、政治结构、事件因果）
├── ontology/      # 本体（类型系统、实体类型定义）
├── chronology/    # 年表（年号纪年映射、公元换算；武帝前用十月岁首历法规则）
├── genealogy/     # 世系（诸侯王/侯国世系、外戚世系）
├── structure/     # 结构（篇章结构、章节层级、引用网络）
├── vocabularies/  # 词表（术语、称谓、避讳字、地名白名单等）
├── taxonomy/      # 分类（官制分类、地理层级、九品分类等）
├── quantity/      # 数量（户口、秩俸、田亩、军力等数值知识）
├── data/          # 数据文件（索引、汇总表等）
└── 标注规范/       # 标注规范文档（既有）
```

## 来源与流水线

- 底本：`data/chapter/`（120 卷纯文本）→ `data/chapter_numbered/`（PN 段落编号）
- 提取工作区：`chapter_md/*.tagged.md`（实体标注，后续里程碑）
- 章节编号：三位卷号 001-120（同卷号分卷用字母后缀，如 001b=高帝纪下、027c=五行志中之下）
- 段落定位：Purple Numbers `[N]`/`[N.k]`，表行 `[rN]`，锚点 `#pn-{number}`
