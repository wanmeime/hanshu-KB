# 汉书版实体标注规范 v1（冷启动 Phase 0 草案）

> 母本：`shiji-kb-reference/skills/SKILL_03a_实体标注.md`（v2.8，史记 130 篇 57 万字实践提炼）
> 方法论依据：`shiji-kb-reference/skills/00-META-03_冷启动.md`（Phase 0-4 五阶段）
> 迁移对照：`kg/标注规范/迁移检查清单.md`
> 状态：**v1 草案（MVP）**——按 META-03，冷启动阶段 5-15 条核心规则即可，不求完美；试点（Phase 3）后升 v2。

## 一、任务目标（What / Why / Success）

**What**：将《汉书》120 篇（纪12/表8/志10/传70，约 74 万字）切分编号后的 `.md` 文本，转为带 `〖TYPE 实体〗` 标记的 `.tagged.md`，标注 18 类名词实体（+4 类动词）。

**Why**：实体标注是九步管线的基础层——事件构建（04）、关系构建（05）、本体构造（06）全部依赖 03a 产出的实体边界；官职/爵位/年号标注直接支撑《汉书》核心价值（官僚制度、封除世系、年代框架）。

**Success criteria（冷启动标准，META-03 §7.1）**：
- 试点 5 篇（高帝纪上 / 百官公卿表上 / 礼乐志 / 韩信传(卷三十四) / 儒林传）完成标注
- 与人工标注重叠度 > 70%；输出格式错误率 < 5%；无系统性误解规则
- 错误模式表 ≥ 15 条归档（这是冷启动的核心产出，而非完美数据）
- 抽样准确率 60-80% 即达标（不追求 >90%，那是迭代目标）

**冷启动性质说明**：本项目非纯冷启动，是"半热启动"——史记的错误模式表与规则可作为先验，但两书体例差异（志、表结构不同；称谓习惯不同）会使部分史记规则失效，须按 Phase 3 试点重验，不能直接照搬。

## 二、符号体系（照搬史记，18 类名词 + 4 类动词）

### 2.1 名词实体（18 类，与史记 v2.8 完全一致）

| 符号 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `〖@X〗` | 人名 | 历史人物、传说人物 | `〖@刘邦〗`、`〖@项羽〗` |
| `〖=X〗` | 地名 | 城邑、山川、郡县 | `〖=长安〗`、`〖=泰山〗` |
| `〖;X〗` | 官职 | 正式职衔、封号（含爵位） | `〖;丞相〗`、`〖;大司马〗` |
| `〖#X〗` | 身份 | 社会角色、地位（非正式官职） | `〖#天子〗`、`〖#太后〗`、`〖#外戚〗` |
| `〖%X〗` | 时间 | 年号纪年、月份、日期、时长 | `〖%元狩四年〗`、`〖%正月〗` |
| `〖&X〗` | 氏族 | 宗族、姓氏集团 | `〖&刘氏〗`、`〖&王氏〗` |
| `〖◆X〗` | 邦国 | 王朝、诸侯国、外邦政权 | `〖◆汉〗`、`〖◆匈奴〗` |
| `〖^X〗` | 制度 | 典章制度、礼法规范 | `〖^推恩令〗`、`〖^郡县制〗` |
| `〖~X〗` | 族群 | 民族、部落 | `〖~匈奴〗`、`〖~羌〗` |
| `〖•X〗` | 器物 | 礼器、兵器、印绶 | `〖•金印紫绶〗`、`〖•节〗` |
| `〖!X〗` | 天文 | 星象、历法 | `〖!日食〗`、`〖!岁星〗` |
| `〖?X〗` | 神话 | 传说、神话人物/事件 | `〖?宓羲〗`、`〖?女媧〗` |
| `〖+X〗` | 生物 | 名词性生物 | `〖+龙〗`、`〖+白虎〗` |
| `〖{X〗` | 典籍 | 古籍书名 | `〖{诗〗`、`〖{春秋〗` |
| `〖:X〗` | 礼仪 | 礼仪、宗庙祭祀 | `〖:宗庙〗`、`〖:郊祀〗` |
| `〖[X〗` | 刑法 | 刑罚、法律 | `〖[腰斩〗`、`〖[族诛〗` |
| `〖_X〗` | 思想 | 哲学概念、文体体裁 | `〖_仁义〗`、`〖_符命〗` |
| `〖$X〗` | 数量 | 军队/距离/重量/金额/户数/石数 | `〖$万六百户〗`、`〖$二千石〗` |

> ⚠️ 口径待定项（承 SKILL_03a 未决问题）：史记 `entity_index.json` 统计表中出现"名物"类（707 条）但符号表无此类型，与"制度〖^〗"的关系不明。汉书版**以 18 类符号表为准**，试点时核对史记索引实际数据后统一口径（项目执行计划 §8-4）。

### 2.2 动词实体（4 类，照搬史记）

| 符号 | 类型 | 示例 |
|------|------|------|
| `⟦◈X⟧` | 军事动词 | ⟦◈击⟧、⟦◈伐⟧ |
| `⟦◉X⟧` | 刑罚动词 | ⟦◉诛⟧、⟦◉赦⟧ |
| `⟦○X⟧` | 政治动词 | ⟦○立⟧、⟦○废⟧ |
| `⟦◇X⟧` | 经济动词 | ⟦◇铸⟧、⟦◇籴⟧ |

### 2.3 消歧语法（照搬史记 v2.7）

`〖TYPE 显示名|规范名〗`：显示短名，索引用规范名。标注即消歧，优先于 JSON 元数据层。

- `〖@季|刘邦〗`（刘邦字季，原文称"季"）
- `〖@太公|刘太公〗`（高帝之父，史失其名）
- `〖=函谷|函谷关〗`、`〖;守|郡守〗`

### 2.4 三层标注互斥（照搬史记铁律）

`〖实体〗`、`〘※成语〙`、`⟦动词⟧` 三层**绝对互斥，不得嵌套**；`〖〗` 内部也禁止再嵌套任何标记（如 `〖%元〖~鼎〗五年〗` 必须写成 `〖%元鼎五年〗`）。

## 三、汉书特有调整（相对史记的差异点）

### 3.1 官职词表：《百官公卿表》白名单升级为主数据源

史记的官职词表是辅助层，汉书项目中**升级为冷启动主白名单**：

- 数据：`shiji-kb-reference/kg/entities/data/hanshu_baiguan.json`（由 `extract_hanshu_baiguan.py` 从本地底本卷十九上提取）
- 实测规模：**116 条**，分 10 类：sangong(9: 丞相/司直/大司徒/大司空/大司马/太尉…)、shifu(5: 太师/太傅/太保/太子太傅/少傅)、jiuqing(32: 光禄勋/典客/别火/中谒者令…)、liqing(31: 中尉/主爵中尉/京兆尹/典属国/内史…)、wenxue(3)、palace(4)、junli(9: 刺史/太守/郡守/关都尉…)、military(1: 前后左右将军)、xianli(1)、**jue(21: 爵位)**。
  - （勘误：`docs/项目执行计划.md` §5.1 写"约300条"，实测 json 为 116 条，以实测为准。）
- 汉书时代新增须补（试点后按语料增补）：尚书台诸官（中书谒者令已在表中）、州牧、西域都护、戊己校尉、使匈奴中郎将、诸将军号。
- **官名屡改是汉书官制最大特点**（太常←奉常、光禄勋←郎中令、大司农←治粟内史、执金吾←中尉、大鸿胪←典客……见卷十九上原文），标注时**按原文用词标注**（原文写"奉常"标〖;奉常〗），改名沿革留给 SKILL_03i 分类层处理，标注层不做归一。

### 3.2 爵位：二十等爵制（jue 白名单 21 条）

- 二十等爵（公士…彻侯/列侯）贯穿全书，是八表主体语料。
- `封…为X侯`、`赐爵X` 共现规则沿用 SKILL_03i L3：爵名入 `〖;〗`（爵位属官职大类）。
- 表类语料高频结构：`〖=平阳〗懿〖;侯〗〖@曹参〗`（封地=地名，谥+爵=爵号，姓名=人名，三段拆分）。

### 3.3 外戚与宗室：〖#〗权重上调

西汉政治主线是外戚与宗室，史记"身份误标"类经验（太后/太子/夫人应标 〖#〗）迁移时**权重上调**：

- `〖#太后〗`/`〖#皇太后〗`/`〖#太皇太后〗`/`〖#外戚〗`/`〖#大司马录尚书事〗身份侧 → 〖#〗；但**带姓特指某人时是人名**：`〖@吕太后〗`、`〖@王皇后〗`、`〖@霍光〗`（见 §4.5 规则 5）。
- 宗室：`〖#宗室〗`、诸侯王子弟称"王子"泛称时 → 不标或按语境；`〖&王氏〗〖&史氏〗〖&许氏〗〖&丁氏〗〖&傅氏〗等西汉外戚宗族是 〖&〗新语料（史记先秦氏族语料的汉书对应物）。

### 3.4 年号纪年：〖%〗成为主力，映射层是 L3 缺口

- 年号纪年密集（建元/元光/元朔/元狩/元鼎/元封/太初/……/元始），**整段标注**：`〖%元狩四年〗`、`〖%太初元年〗`，不要拆成 `〖%元狩〗四年`。
- 太初改历（前104）前后历法不同（十月岁首→正月岁首），是**年代消歧层（SKILL_03g/04c）**的事，标注层只管把时间词完整标出。
- `reign_periods.json` 中昭帝以后年号、王莽时期（居摄/始建国/天凤/地皇）缺失，需在 M2-M4 间扩充——**标注层不受阻**，照常标 〖%〗。
- 是否为年号新增 `〖*〗` 独立类型：**试点后决策**（倾向复用〖%〗+后处理解析，项目执行计划 §5.5）。

### 3.5 表8篇标注注意（表类为汉书新增重心）

- 表格行采用 PN 体系 `[rN]` 行编号（沿用史记十表方案），格内实体照常标注。
- 《古今人表》是全新表型：近 2000 人按九品分格。人物均标 `〖@〗`（传说人物如太昊帝宓羲氏标 `〖@太昊帝宓羲氏〗` 还是 `〖?〗`——**待定**，倾向：有系谱定位的远古帝王标〖@〗+消歧规范名，纯神话事件标〖?〗，试点定）。
- 《百官公卿表》上卷官制散文是官职词表黄金语料（白名单即从中提取），标注密度要求最高。
- 侯表"国除/坐X免/薨/嗣"等术语先不做实体标注（属事件层 SKILL_04b），只标其中的人名/地名/爵号/年号。

## 四、MVP 核心规则（10 条，够试点用即可）

> 来源：SKILL_03a §1.3/§一.4 + 汉书调整。每条可执行、可验证。

**规则 1（铁律）只加标记，不改原文**
不得增删替换任何原文字符（含标点、引号、空格）。验证：标注文件去除全部标记后必须与底本逐字一致（`lint_text_integrity.py`）。严禁引入半角引号 `""`。

**规则 2 名词性用法才标**
标名词性实体；动词/形容词/比喻用法不标（"龙颜"不标〖+龙〗）。同段首次出现必须标，后续可选。

**规则 3 人名只含姓名本体**
`[国籍/出身][官职/封号][姓名]` 结构拆开标：`大司马大将军王莽` → `〖;大司马〗〖;大将军〗〖@王莽〗`；`沛公`→ 人名〖@沛公|刘邦〗（已固化为专称时整体作人名+消歧）。人名标注回答"叫什么"，不回答"是谁的什么人"。

**规则 4 国+谥号+爵=人名；国+爵（无谥）=官职**
`〖@齐悼惠王〗`（特指刘肥）是人名；`〖;齐王〗`（泛称可指任一任）是官职。带姓的帝王后妃特指人：`〖@吕太后〗`、`〖@孝武李夫人〗`；无姓泛称：`〖#太后〗`、`〖#皇后〗`、`〖#天子〗`。

**规则 5 官职/身份/亲属三分**
朝廷正式职位（白名单内）→ `〖;〗`；制度性社会角色（天子/诸侯/太子/外戚/丞相之子称"诸子"类）→ `〖#〗`；纯亲属描述词（父/子/兄/长子/苗裔/子孙/甥）→ **不标**。太子有法定继承地位标〖#太子〗，"长子"仅排行不标。

**规则 6 邦国不存人名**
`〖◆〗`只标政治实体本身。`齐王`不是 `〖◆齐〗〖;王〗`；`齐桓公`式称呼合并为人名。西汉主体：`〖◆汉〗`+诸侯王国+`〖◆匈奴〗`；西域诸国（《西域传》）标〖◆〗。**匈奴职官**（单于/左右贤王/谷蠡王/当户/且渠/骨都侯）标 `〖;〗` 还是 `〖#〗`——**待定**（史记有"外邦职"类规则可循，倾向〖;〗，试点定）。

**规则 7 时间整标、时长消歧**
年号+年数整体标：`〖%元光六年〗`。纯纪年/月份/干支日默认 〖%X〗；时长语义（在位X年/立X年/X年而薨/三年丧毕）必须 `〖%X|时长〗`。判断：能替换为"第X年"且语义不变 → 时长。

**规则 8 数量与时间的边界**
以年/月/日/岁结尾或年号/干支开头 → `〖%〗`；以量词结尾（人/里/城/户/骑/乘/斤/金/石/尺/匹/级）→ `〖$〗`（侯表"万六百户"、秩级"二千石"、军额"三万人"全入〖$〗）。不标：年龄（年二十）、虚指（千秋万岁）、代词性数词。

**规则 9 结构元素不标注**
各级标题行、`[1]`/`[1.1]`/`[rN]` 编号、`:::` 块标记本身不标；汉书篇末"**赞曰**"块：标记语法不标，块内正文照常标（史记"太史公曰"对应物，**赞曰评论内容标注策略待定**——史记原则是评论性内容不提取事件，但实体照标）。

**规则 10 完整包裹、严禁嵌套**
每个标记完整包裹一个实体词，不得跨越标点或吞噬句子（`〖•驷马〗`✓）；`〖〗`内禁止再嵌套`〖〗`/`⟦⟧`/`〘〙`；自动标注脚本对已标区域必须先掩码（掩码+长词优先）。

## 五、示例（取自本地底本真实原文）

**例 1 叙事传类（卷一上·高帝纪）**

原文：
```
九月，沛令欲以沛应之。掾、主吏萧何、曹参曰：“君为秦吏……”
```
标注：
```
〖%九月〗，〖;沛令〗欲以〖=沛〗应之。〖;掾〗、〖;主吏〗〖@萧何〗、〖@曹参〗曰：“君为〖◆秦〗吏……”
```
要点：沛令=地+官拆分（官职）；萧、曹后文省称"萧、曹"时仍标人名（〖@萧〗〖@曹〗，姓氏省称消歧 `|萧何|曹参`）。

**例 2 官制志类（卷十九上·百官公卿表）**

原文：
```
相国、丞相，皆秦官，金印紫绶，掌丞天子助理万机。
```
标注：
```
〖;相国〗、〖;丞相〗，皆〖◆秦〗官，〖•金印紫绶〗，掌丞〖#天子〗助理万机。
```
要点：官名连续并列逐个标注；"秦官"的秦是朝代=〖◆秦〗；印绶入〖•〗；天子是身份非人名。

**例 3 表类（卷十六·高惠高后文功臣表首行，维基文库补源版）**

原文（wikitext 转纯文本并转简以示例；繁体原文见 `data/raw/hanshu_tables/卷016_高惠高后文功臣表第四.txt`）：
```
平阳懿侯曹参　以中涓从起沛，至霸上，侯。……以右丞相，侯，万六百户。
```
标注：
```
〖=平阳〗懿〖;侯〗〖@曹参〗　以〖;中涓〗从起〖=沛〗，至〖=霸上〗，〖;侯〗。……以〖;右丞相〗，〖;侯〗，〖$万六百户〗。
```
要点：表首列三段拆分（封地/谥爵/姓名）；"起沛"的沛是地名非邦国；户数入〖$〗。

**例 4 年号纪年（卷十二·平帝纪体）**

```
〖%元始五年〗正月，〖!祲〗见于〖=长安〗……（示意）
```
要点：年号+年数整段一标，不拆。
