# hanshu-KB（《汉书》历史知识库）

《汉书》历史知识库项目 —— 将《汉书》结构化，形成可复用、可开源的人物/事件/地点/关系知识图谱。

## 定位

- 复用 shiji-kb（报捷）的可迁移 SKILL 管线方法论
- 覆盖《汉书》（前四史之一，西汉 230 年历史，约 120 卷 / 80 万字）
- 目标：与已有《史记》项目（shiji-map）衔接，逐步扩展 24 史

## 目录规划（待建设）

- `data/`       原始文本、结构化数据
- `scripts/`    抽取/处理管线
- `kb/`         知识库产物（人物/事件/地点/关系）
- `docs/`       标注规范、SKILL 文档、进度记录

## 数据源参考

- 《汉书》全文：维基文库等开放文本
- 人物/地理：CBDB（哈佛+北大+中研院）、CHGIS
- 实体标注参考：GuNER 2023（二十四史）、古白平行语料库
